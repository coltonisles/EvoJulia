Image Imitation Using Julia Set Fractals 

 

Description 

This project developed a system that takes in a user uploaded image, like a photo of a mountain, and generates a fractal that visually resembles it. The target art style of this is the Julia set fractals. The Julia set are fractals generated by iteration of a complex function,

While the complex constant c dictates the foundational shape of the fractal, the system allows for viewport manipulation (zoom and coordinate offsets) with color mapping happening post generation via histogram matching. This allows the system to locate, scale, and colorize the specific structure within the infinite Julia set fractal to better match the target.  

To automate the creation of these fractals, the system uses a genetic algorithm (GA). The GA treats the mathematical parameters of the Julia set (the constant c, viewport) as its genotype. It constantly evolves these parameters to minimize the visual difference between the rendered fractal and the user-provided target image.  

A genetic algorithm works best for this task as it addresses the “Inverse Fractal Problem” [2]. Typically, generating a fractal is a forward process: parameters are put into the function, and the computer renders the image. This project reverses this workflow starting with an arbitrary, non-fractal target image. The system searches for the parameters to produce a fractal that mimics the target. This is difficult as the parameter space is chaotic; changing the c constant by a tiny amount may scramble the output image.  

Since the search space for these parameters is massive and unpredictable, GAs work well because they are designed to search large spaces and find optimal solutions. Past research used AI for evolving graphics but often relied on a "Human-in-the-Loop" method where a person judged the best-looking image. This is done because aesthetic fitness is highly subjective and hard to automate. Other automated GA methods focused on evolving raw pixel grids or compressing data using affine transformations. However, past research applying GAs to the inverse fractal problem using Iterated Function Systems (IFS) found that standard GAs can struggle because the interacting equations deceive the algorithm's crossover mechanics. By targeting the Julia set, which relies on a single core equation, this project mitigates that risk. Defining a fitness function that actively compares the spatial and visual layout of the evolving Julia set to the target image allows the GA to automate the trial-and-error process, successfully generating fractals that mimic the target. 

 

Methodologies 

Method 1: Layered Approach 

The system utilizes a GA to search the parameter space of the Julia set to find the optimal structural match for the target image. The generation followed an evolutionary loop consisting of initialization, evaluation, selection, crossover, and mutation.  

Genotype Structure and Initialization 

The genotype contains an array of six distinct fractal layers. For each layer, the algorithm tracked float values for the real and imaginary numbers to form the Julia set complex constant c, along with viewport controls (X/Y offsets and zoom level). During initialization, a population of 150 to 200 genotypes was generated. To ensure genetic diversity, values were initialized with randomized values for each parameter. Each parameter had its own constraint, c values between -1.0 and 1.0, offsets between -0.5 and 0.5, and zoom levels between 0.5 and 2.5. 

Fitness Evaluation 

To automate the scoring process, the system compared the structural layout of the Julia set to the target image. OpenCV’s Canny edge detection algorithm processed the target image, isolating the contours to create a weighted map. The GA’s fitness function then evaluated how well the generated fractal layers align with the map using a weighted Mean Squared Error (MSE) score.  

To handle the computational load of calculating the escape time for each pixel over the entire population, the evaluation was optimized using CuPy. By using CuPy, the system can perform 4-dimensional matrix operations on the GPU rather than CPU, evaluating a batch of 25 fractals simultaneously rather than sequentially. 

Evolution 

 	After evaluation the top performers were selected to breed based on their fitness scores. The systems used an elitism approach, preserving the absolute best genotype unmodified for the next generation. The remaining offspring go through a uniform crossover method; each parameter in each layer was randomly selected and inherited by the child.  

Finally, the mutation follows a simulated annealing approach to balance exploration and exploitation. A precision factor is used to gradually reduce the mutation rate and range over the generations. This allowed for an initially high mutation rate to explore the search space quickly and then dynamically turned to small adjustments as the algorithm tried to match the target features. 

 

Phase 2 – Constructing the Mosaic using a second Generic Algorithm 

Once the Julia set fractal has been generated using the layered approach, a sample of 20 fractal genomes was pulled from each layer. This provided the Mosaic building process with 120 different fractal images
